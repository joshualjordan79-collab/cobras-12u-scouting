# Washington Cobras 12U: opponent scouting reports

Weekend opponent scouting reports built from GameChanger box scores and play-by-play text. `index.html` lists the reports newest first; each report is in `reports/YYYY-MM-DD.html`.

Every page is self-contained HTML (inline CSS/SVG, no external assets). Charts enlarge with plain links and work with JavaScript off; a small inline script only adds tap-to-sort on table headers.

Live site: https://joshualjordan79-collab.github.io/cobras-12u-scouting/
